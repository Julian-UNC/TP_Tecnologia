\section{Depuración y Funcionamiento}

Para depurar el circuito en caso de una eventual falla es necesario hacer dos tipos de análisis, el comportamiento en contínua, sin señal de entrada, y el comportamiento con señal de entrada.

El primero se realiza para verificar que el amplificador está en su punto de operación correcto, basandose en los dátos de la hoja de datos del componente. Para esto se verifica que las tensiones y corrientes son las correctas, utilizando un multímetro.

Una vez que se confirma que el punto de operación es el correcto, se inyecta la señal de entrada para verificar que la amplificación es la deseada. Para ello, se mide la salida con un osciloscopio y, conociendo el valor de entrada, es posible calcular la ganancia de tensión.
